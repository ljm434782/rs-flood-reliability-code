# Preparing a repository

This ZIP is a locally prepared public release candidate. Nothing was pushed
or uploaded, and no public repository, DOI or journal supplement was assigned.
The author-selected project-level license is MIT License; the root LICENSE
covers author code, while third-party and data licenses remain separate.

Use the contents of the unpacked
`rs-flood-reliability-code-public` directory as a repository root. Publish
actual files and folders, rather than only the delivery ZIP. Retain the
third-party SMAGNet license, provenance summaries, omission inventories and
verification limitations. Do not add raw imagery or tensor checkpoints to
this repository as part of this release.

Any future release URL or DOI must be the real assigned address. Update
manuscript access statements only after the actual distribution exists and
its scope has been checked. This preparation task does not edit paper URLs.
