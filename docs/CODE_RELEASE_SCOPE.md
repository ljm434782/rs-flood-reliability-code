# Public release scope

This distribution is a new journal-facing code release candidate prepared
from an immutable original archive. It supplies cached presentation
reproduction, scientific implementation and objective historical provenance.
It does not distribute raw images/native labels or model tensors, recreate
private historical execution control, or claim complete inference reproduction.

All retained numerical evidence, process memberships, scientific source and
temperature/checkpoint metadata were copied unchanged. Public config
projections omit administrative text only. A public-only fail-closed gate
replaces the original administrative function without altering scientific
helpers. The original freeze/attestation records were excluded rather than
modified with an invalid inherited hash. Duplicate historical snapshot files
were inventoried and omitted; unique scientific implementations were retained.

No experiment, model fitting, study-temperature refitting, raw-data inference,
data download, repository creation or publication was performed. Verification
uses the existing selected synthetic/unit tests and saved-summary renderer.
